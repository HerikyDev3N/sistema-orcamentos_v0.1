# Sistema de Orçamentos e Captação de Clientes

Sistema web desenvolvido para empresas de instalação e manutenção de ar-condicionado, com foco em captação de clientes, gerenciamento de leads e organização de solicitações de orçamento.

## Sobre o projeto

O sistema permite que clientes solicitem um orçamento diretamente pelo site, informando seus dados, cidade, tipo de serviço, descrição do problema e fotografias.

As solicitações são armazenadas e disponibilizadas em um painel administrativo para acompanhamento dos leads.

## Funcionalidades

### Área do cliente

- Solicitação de orçamento
- Cadastro de nome
- Cadastro de WhatsApp
- Cadastro de cidade
- Seleção do tipo de serviço
- Descrição do problema
- Envio de fotografias
- Validação dos dados enviados

### Painel administrativo

- Visualização dos leads recebidos
- Busca por cliente
- Filtro por status
- Visualização dos dados do cliente
- Visualização da descrição do problema
- Visualização das fotos enviadas
- Contato direto pelo WhatsApp
- Alteração do status do lead
